# 踩过的坑

两处实现各自撞过的墙，合并去重。**这份文档比代码值钱** —— 代码你抄得走，坑你抄不走，除非有人告诉你。

来源标记：
`[上游]` = 上游 0.3.3 代码注释里已经写明的结论（照抄可以，别当成自己的发现）；
`[DSH]` = 在 DSH 插件那侧改造时撞的；`[面板]` = 移植进游戏面板网页时撞的；`[宿主]` = 面板的 C#/PowerShell 宿主工程。

## 一、动画代码本身的坑（改之前必读）

### 1. CSS 写在 JS 字符串里，换行必须是字面的 `\n`　`[DSH]`

`CSS_550C` 是**双引号 JS 字符串**，内部只能用两个字符的 `\n`。写真实换行会把字符串字面量截断，
整个插件语法崩掉。**这个坑犯过两次**（一次是 CSS 里的真实换行，一次是在模板字符串的 CSS 注释里写了反引号
—— 一个反引号就能提前结束模板字符串，把整个 bundle 带走）。

> **对策**：写完立刻 `node --check`；改动脚本里带"失败自动回滚"。

### 2. CSS 动画压过一切普通声明，**连内联也压**　`[DSH]`

`.boot-text.show{animation:fadeIn … forwards}` 会把 `opacity` 钉在末态，
此时 `#bootText{opacity:0}` 无效，**内联的 `opacity:0` 同样无效**。
只有**作者级 `!important`** 压得住。

这就是那行 `550C SYSTEM BOOT` 当初怎么都不消失的原因。同一道理适用于水印态的收尾。

### 3. 界面可见性**不能**只靠 transition 完成　`[DSH]`

交接的"让开"如果只依赖 `background-color` 过渡跑完，那么**后台标签页 / 最小化窗口会被 Chromium
节流甚至丢弃过渡**，结果停在中途：`#boot` 停在 `rgb(0,0,0)`、宿主停在 `rgb(5,4,3)`
—— **看不见但能点**，两种失败里最糟的一种。

> **对策**：`transitionend`（监听器要挂在 shadow 树**里面的元素**上，挂 document 会被重定向到 host、
> 永远匹配不上）+ 一个不欠过渡任何东西的超时兜底（`RETIRE_FALLBACK_MS = 4600`）。

### 4. "透明的全屏层"仍然是活着的合成层　`[DSH]`

`#boot` 只变透明、不退场的话，它依然是一层 1440×900、`z-index:2000` 的合成层压在界面上。
今天不咬人只是因为继承了 `pointer-events:none`；**上一版正是栽在这里** —— 那版给了 `pointer-events:auto`，
吃掉了所有点击。交接完成后应该**真正摘掉它**（`display:none`）。

### 5. `filter` 的数值是**相对 viewBox** 的，换版式必须重算　`[DSH]`

550C 原稿的 `filter="url(#despike)"`（`stdDeviation="2.2"` + `feFuncA slope5/intercept-2`）
是按 **800×230** 调的，2.2 只占 0.27%。把 viewBox 切成 26 / 95 / 58 宽之后，
同一个 2.2 变成 **8.5% / 2.3% / 3.8%** 的模糊，alpha 又被 `intercept=-2` 削掉低值部分，
**细笔画直接归零、图形整片消失**。

### 6. `clipPath` 是 `userSpaceOnUse`，会跟着**引用元素的坐标系**走　`[DSH]`

外层 `<g transform="translate(...)">` 平移之后，`clipPath` 里的 rect **自己就跟着走了**。
再手动平移一次 rect → **等于平移两倍** → 裁剪窗口跑到图形外面 → **图形被整条裁没**。

### 7. 拆成多个 `<svg>` 会破坏 `getBBox()` / `clip-path` 的行为　`[DSH]`

把一条 18-path 的 logo 拆进三个独立 `<svg>`、每个只给一个**估算**的 viewBox 之后：

- `playBoot` 里 `paths.map(p => p.getBBox())` 拿不到有效包围盒 → 抛错 →
  `start()` 走 settle 分支 → **书写动画整段被跳过**（表现是"动画直接消失了"）
- 估算的 viewBox 切窄了 → **字形圆弧被裁成直边**（表现是"圆的变成方的"）

**550C 是单个 `<svg>`，那是已知能工作的形态。** 要做多行排布，用**单 SVG + `<g transform>`**。

### 8. 模糊半径必须跟着标记的**实际尺寸**走　`[DSH]`

`blur(8px)` 对 540px 宽的横条是"磨砂"，对 96px 宽的图形行就是"抹平"。
每次改版式都要重校，**而且要拿最小的那一行去校** —— 先消失的永远是最小的。

### 9. `backdrop-filter` **不采样下层水印**　`[面板]`

水印埋在背景层（`z-index:0`）时，会被卡片的毛玻璃挡掉，只剩缝隙里一点，看着就跟没有一样
—— GPU 合成下毛玻璃不采样下层的水印层。

> **对策**：水印层要提权。面板侧最终让 `#c550Bg` 独立成层并调到能看见的位置；
> DSH 侧则把字形迁进独立的 `.dsh550c-marklayer`（`position:fixed`、`pointer-events:none`）。

### 10. 曾经做过"中心磨砂窗"，**已废弃**　`[DSH]`

它正好压在对话渲染区，挡住了正文。**水印是布景，不许占据应用需要的地方。**
代码里留了明令注释：别在这里重新引入居中层。

## 二、验证方法的坑（这一节最防自欺）

### 11. 无头浏览器 ≠ 真实窗口　`[面板]`

这一轮在这上面翻车四五次：无头（软件渲染）测得到水印，真实窗口（GPU 合成）看不到。
**最终判据只能是用户的眼睛**，像素统计只能当辅助。

### 12. "区域平均亮度"不适合测细线图形　`[面板]`

字形笔画只占边界框约 20%，平均一下就被摊平（0.16 透明度时实测只有 7 灰阶提升，
但笔画处其实有 39）。为此反复误判、来回调了 `0.07 → 0.16 → 0.22 → 0.12 → 0.55` 好几轮。

### 13. `animation: … forwards` 会锁死属性　`[面板]`

同坑 2。那条小字因此不跟着淡出、要多停留 1.6 秒才随整层消失。

### 14. 我的检查脚本本身会骗人，**每条 FAIL 都要去看原文**　`[DSH]`

至少三次假阳性：

- 全文件搜 `fill:#141414`，命中的是 `--caption-fill:#141414`（桌面标题栏配色，无关）
- 全文件搜 `clip-path` 报了 4 处，全是上游原稿自带
- 搜 `id="whale"` 搜不到 —— 因为 `BOOT_MARKUP` 是**转义过的 JS 字符串**，实际存的是 `id=\"whale\"`

还有一次是**预期值我自己数错**（某个变量本来就该出现 2 次）。

> **对策**：先用行号逐条查证，再改预期值，**不要反过来**。

### 15. 用 headless Edge 做视觉验证，在这台机器上行不通　`[DSH]`

`msedge --headless=new --dump-dom` 在沙箱里**起不来也不退出**，空转烧掉 **1002 秒 CPU**，
把机器拖住（用户以为 DSH 卡死了）。

**另外**：这台机器的 Ollama 只配了 `deepseek-r1:7b`（**非多模态**），
Python 侧 `cairosvg` / `svglib` / `reportlab` / `wand` **都没有**（只有 `PIL`、`numpy`，
渲染不了 SVG 贝塞尔曲线）。**所以"AI 自己看效果"这条路目前是断的。**

### 16. 改动后要确认窗口真的换了页面　`[面板]`

面板宿主原本的逻辑是"页面文件比浏览器进程新才重开窗口"，但 `GetWindowThreadProcessId`
拿到的是 Edge 的**渲染子进程**，启动时间总是很新 → 永远判定"不用重开" →
**改了 `monitor.html` 用户那边一个字都不生效**。

> **对策**：服务启动时无条件重开；页面自身的 `__PAGE_VER__` 当第二道兜底。
> 曾用 OCR 读用户屏幕上的文字（读到"磁盘读写 · 网络"）才证明页面是最新的 —— 之前差点冤枉成"窗口没更新"。

### 17. 新版 DSH 的 GUI 有认证，服务端 bundle 比对**已失效**　`[DSH]`

对 `http://127.0.0.1:19387/plugins/dsh-550c-boot/client.js` 请求返回 **404**、
对 `/` 返回 **401**。所以早期那套"请求服务端 bundle 比对内容"的验证方式在新环境用不了了，
目前只能做**文件层**验证。

## 三、宿主工程的坑（GameHud 侧）　`[宿主]`

移植动画时顺带踩的，与动画无关但同一个工程：

- **`.NET string.Format` 的 `}}` 转义陷阱**：`{4:F1}}}` 里的 `F1}` 会被当成格式说明符，
  输出字面量 `F1`。拼 JSON 别用 `{{ }}`，改用字符串拼接。
- **PowerShell 5.1 把全角引号 `“ ”` 当字符串分隔符** → 解析错误、**整段脚本不执行**。
  （踩了至少三次）
- **ParserError 会让整个脚本一行都不跑**，但前一次的外部副作用可能已生效 →
  报错后一定要回头确认文件到底改了没有。
- **`$home` / `$pid` 是 PowerShell 保留变量**，赋值会失败。
- **变量复用覆盖**：`$dst` 先当目录用、后被 `Copy-Item` 覆盖成文件路径，
  再传给 `Start-Process -WorkingDirectory` 就报 DirectoryNotFound（服务根本没起来）。
- **沙箱用作业对象管进程**：命令超时被中断会**连带杀掉刚启动的服务**。
- **重启服务时端口可能还被旧实例占着** → 新实例启动失败自己退出。
  等待循环要等到**真的一次 TCP 连接失败**为止。

## 四、两条环境事实（否则会改错文件）

### 18. 有两份 `dsh-550c-boot`，互不相干　`[DSH]`

- `<DSH_HOME>\profiles\desktop\node_modules\dsh-550c-boot\` ← **新版生效的这一份**
- `D:\deepseek harness\profiles\node_modules\dsh-550c-boot\` ← 旧 0.1.0-rc.5 客户端的，**别动**

这两份**不是硬链接**（`fsutil hardlink list` 各自只有一个链接），只是被复制过所以内容曾相同。
**改一份不会影响另一份。**

### 19. "写完即验、失败自动回滚"要成为流程　`[DSH]`

中途把界面改死过一次：`WATERMARK_CSS` 常量定义了但忘了拼进 `style.textContent`，
导致水印态只让宿主要素透明、`#boot` 的黑底却留着不透明 —— **满屏黑但能点**。
用户自己回滚的（坏文件留档为 `client.js.broken-watermark`）。

此后确立流程：**先在工作区改 → 逐项验证 → 再部署**，
每次动手前存一份 `<文件>.bak-before-<这次改了什么>`。
